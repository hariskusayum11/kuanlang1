# 35 — เส้นขอบชุมชนบนแผนที่ (`/map` และแผนที่สาธารณะ)

สถานะ: ใช้งานแล้วในเครื่องพัฒนา (2026-10-19) · **ขอบเขตทั้ง 5 ชุมชนยังเป็นร่างที่ไม่ได้รับรอง**

## ที่มาของข้อมูล

- เจ้าของระบบส่งไฟล์โครงร่างชุมชนเมื่อ 2026-10-19 → แปลงเป็น polygon แล้วตรวจด้วยตาว่าลำดับถูก
  (PW01 ปลักหว้า · KS01 ควนสันติ · TK01 ท่าเคียน · PM01 ประสานมิตร · NK01 หน้าควน)
- ไฟล์ต้นฉบับในรีโป: `database/geo/community-boundaries.geojson` (`properties.code` = รหัสชุมชน)
- นำเข้าด้วย `npx tsx scripts/import-boundaries.ts database/geo/community-boundaries.geojson --source "..."`
  → ตาราง `community_boundary` (`geom geography(MultiPolygon,4326)`) เวอร์ชัน 2, `isApproved = false`
  (เวอร์ชัน 1 คือสี่เหลี่ยมตัวอย่าง ถูกปิดด้วย `effectiveTo` แล้ว ไม่ได้ลบ)
- **ยังไม่รับรอง:** เป็นโครงร่างจากชุมชน ไม่ใช่แนวเขตทางการจากเทศบาล/กรมที่ดิน
  เมื่อได้ไฟล์ที่รับรองแล้วให้นำเข้าซ้ำด้วย `--approved` สคริปต์จะปิดเวอร์ชันเดิมและเพิ่มเวอร์ชันใหม่เอง
  UI เปลี่ยนจากเส้นประเป็นเส้นทึบและเอาข้อความ "ร่าง" ออกโดยอัตโนมัติ

## การอ่านข้อมูล (`lib/geo/community-boundaries.ts`)

`getCurrentCommunityBoundaries({ communityIds?, precision? })` อ่านผ่าน raw SQL (geom เป็น Unsupported ใน Prisma)

| ขั้น | SQL | เหตุผล |
| --- | --- | --- |
| เลือกเวอร์ชัน | `effectiveTo IS NULL` + `DISTINCT ON (community) ORDER BY version DESC` | ถ้ามีแถวปัจจุบันค้างเกินหนึ่งแถว ใช้เวอร์ชันล่าสุด |
| ลดจุด | `ST_SimplifyPreserveTopology(geom, 0.00002)` (≈ 2 ม.) | ตัดจุดซ้อนจากการวาดมือ รูปร่างที่มองเห็นไม่เปลี่ยน |
| ส่งออก | `ST_AsGeoJSON(..., 6)` ภายใน · `5` สาธารณะ | 6 ตำแหน่ง ≈ 0.1 ม. · 5 ตำแหน่ง ≈ 1 ม. ลด payload |
| ตำแหน่งป้าย/หมุด | `ST_PointOnSurface(geom)` (คำนวณจากรูปทรงเต็ม) | รับประกันว่าอยู่ในพื้นที่ ต่างจาก centroid ที่อาจหลุดนอกรูปเว้า |

- ชุมชนที่ถูกลบ (`deletedAt`) หรือปิดใช้งาน (`isActive = false`) ไม่ถูกส่งออก
- ข้อความ GeoJSON ผ่าน `parseBoundaryGeometry` (`domain/geo/community-boundary.ts`) ก่อนถึง Leaflet:
  รับ Polygon/MultiPolygon เท่านั้น · ทิ้ง ring ที่มีพิกัดเพี้ยน · พังทั้งก้อน = ไม่วาด (ดีกว่าวาดผิดที่)
- ขนาดจริงของ 5 ชุมชน (GeoJSON หลัง simplify): รวมประมาณ 3 KB — เล็กพอสำหรับหน้าสาธารณะบนเน็ตช้า

## ตำแหน่งหมุดชุมชน

`communityMarkerPosition(labelPoint, centroid)`: ใช้จุดภายในขอบเขตก่อน → ไม่มีขอบเขตใช้
`community.centroidLat/Lng` เดิม → ไม่มีทั้งคู่ = ไม่วางหมุด (ไม่เดา)

**ไม่เขียนทับคอลัมน์ centroid** — centroid เดิมคลาดจากพื้นที่จริง 1.5–5 กม. แต่ยังเป็นค่าสำรองของชุมชน
ที่ไม่มีขอบเขต (เช่น ชุมชนที่เพิ่มในอนาคต) · เทสต์ยืนยันว่าคอลัมน์ไม่ถูกแก้

## แผนที่ภายใน `/map`

- แผง "ชั้นข้อมูล" → กลุ่ม "พื้นที่" → แถว **เส้นขอบชุมชน** (จำนวน = ชุมชนที่มีขอบเขต) เปิดเป็นค่าเริ่มต้น
  ปิดแล้ว URL เป็น `boundary=off` (กติกา URL ตาม docs/33) · นับเป็น 1 ชั้นใน "เปิด X จาก Y ชั้น"
- วาดเส้นขอบ + พื้นจาง + ป้ายชื่อชุมชนที่ `labelPoint` · ป้ายและเส้นอยู่ใต้หมุดครัวเรือนเสมอ
  (overlayPane / `zIndexOffset: -1000`, ป้ายไม่รับคลิก)
- เลือกชุมชนในตัวกรอง → ชุมชนนั้นเด่น ชุมชนอื่นจางเป็นบริบท และกล้องครอบขอบเขตของชุมชนนั้นด้วย
  (เห็นทั้งพื้นที่แม้ยังไม่มีหมุด) · ไม่มีหมุด/จุดสำคัญเลย → ครอบทุกชุมชน · ไม่เลือกชุมชน → กล้องครอบหมุดเหมือนเดิม
- คลิกพื้นที่ → popup ชื่อ/รหัส/เวอร์ชัน/สถานะรับรอง/ที่มา · ข้อความ "ร่าง — ยังไม่รับรอง" ใช้สี `sun` (คำเตือน)
- ขอบเขตอ่านตาม community scope ของผู้ใช้ (ปัจจุบันเห็นทุกชุมชนตาม #R7-B)

## แผนที่สาธารณะ (หน้าแรก)

- `getPublicMapData()` คืนต่อชุมชน: `id, nameTh, lat, lng, positionSource, boundary, boundaryApproved` เท่านั้น
  — ไม่ส่ง source/version · **ไม่มีข้อมูลรายบ้าน** (ขอบเขตเป็นระดับชุมชน) · เทสต์ whitelist ฟิลด์ไว้แล้ว
- เส้นประ + คำอธิบาย "เส้นขอบชุมชน (ร่าง — อยู่ระหว่างตรวจสอบ)" ใต้แผนที่ · popup หมุดบอกว่าเป็น
  "ภายในเขตชุมชน" หรือ "จุดศูนย์กลางโดยประมาณ" ตามที่มาของตำแหน่ง

## สีและสไตล์

Leaflet ใส่สีเป็น presentation attribute บน `<path>` ซึ่งแพ้ CSS เสมอ จึงคุมสีด้วย Token ใน
`app/globals.css` (`@layer components`) — คอมโพเนนต์ส่งแค่ `className`, ไม่มีค่า Hex

| คลาส | ใช้กับ |
| --- | --- |
| `.map-boundary` | เส้น `brand-600` + พื้น `brand-500` จาง 7% |
| `.map-boundary-draft` | เส้นประ (ขอบเขตร่าง) |
| `.map-boundary-dim` | ชุมชนที่ไม่ได้เลือก (`slate`) |
| `.map-satellite .map-boundary` | เส้นสว่าง/หนาขึ้นบนพื้นดาวเทียม (ใส่คลาสที่ container ด้วย `classList` ไม่ใช่ prop — React จะลบคลาสของ Leaflet) |
| `.map-boundary-label` | ป้ายชื่อชุมชน |

- การรับรองขอบเขต (หน้าจออนุมัติ / `approvedById`) — ตอนนี้ทำได้ด้วยการนำเข้าซ้ำพร้อม `--approved` เท่านั้น

- ฐานข้อมูล production ยังไม่ได้นำเข้าขอบเขต (การ deploy เป็นงานของเจ้าของระบบ)
