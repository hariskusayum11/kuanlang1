# 39 — แผนที่ความรุนแรงน้ำท่วมบนหน้าสาธารณะ

**Owner Decision 2026-10-19** (ประชุม ข้อ 1 และ 6) · สถานะ: **บังคับใช้แล้ว**

แผนที่บนหน้าแรก (และหน้าศูนย์อาสาสมัคร) แสดง **ช่องพื้นที่ประมาณ 200 × 200 ม.** ระบายสีตามตัวชี้วัดที่เลือก:

| ตัวเลือก | ตัวชี้วัด | ช่วงสี |
|---|---|---|
| ระดับน้ำเฉลี่ยที่เคยท่วม | ระดับน้ำเฉลี่ยที่ครัวเรือนในช่องเคยเจอ | 9 ช่วงเดียวกับฮีตแมปภายใน ถึง "5 ม. ขึ้นไป" (`domain/flood/depth-scale.ts`) |
| สัดส่วนบ้านพื้นต่ำกว่าถนน | สัดส่วนบ้านที่พื้นต่ำกว่าถนน | <20% · 20–39 · 40–59 · 60–79 · 80%+ |
| จำนวนวันที่ท่วมเฉลี่ย | จำนวนวันที่ท่วมเฉลี่ย (ครั้งล่าสุด) | <1 · 1–2 · 3–6 · 7–13 · 14+ วัน |

## ปุ่มบนแผนที่ (Owner Decision 2026-10-21)
เจ้าของระบบไม่ต้องการแถวปุ่มข้อความเหนือแผนที่ — ปุ่มควบคุมทั้งหมดจึงอยู่ **บนตัวแผนที่** แบบเดียวกับปุ่มซูม:

- **มุมขวาบน — ปุ่มชั้นข้อมูล** (ไอคอนแผ่นซ้อน · `aria-label` "ชั้นข้อมูลและเลือกชุมชน") กดแล้วเปิดแผงเล็กข้างปุ่ม:
  เลือกชุมชน (ซูมไปที่เขตชุมชน) และเลือกตัวชี้วัดความรุนแรงตามตารางด้านบน หรือ "ไม่แสดงความรุนแรง"
  · ปิดแผงด้วยการกดปุ่มเดิม แตะที่อื่นบนหน้า หรือ Esc
- **ใต้ปุ่มชั้นข้อมูล — ปุ่มขยายเต็มจอ** (ไอคอนอย่างเดียว · ป้าย/tooltip "ขยายเต็มจอ" ↔ "ย่อแผนที่ (Esc)")
  · Esc ปิดแผงชั้นข้อมูลก่อน กดอีกครั้งจึงออกจากเต็มจอ
- ชุมชนที่เลือกอยู่แสดงเป็นป้ายเล็กข้างปุ่มซูม (มุมซ้ายบน) · คำอธิบายสีคงอยู่มุมซ้ายล่าง
- ปุ่มสูง 44 px (เป้าสัมผัสขั้นต่ำ — หน้าสาธารณะ mobile-first) · แผงกว้างไม่เกิน `100vw − 7.5rem` จึงไม่ล้นจอโทรศัพท์

รายละเอียดทางเทคนิค: ปุ่มและแผงเป็น element ของ React วางทับ (absolute, `z-[1000]`) **ข้าง** `div` ของ Leaflet
ไม่ใช่ลูกของ Leaflet จึงไม่ส่งคลิก/ลากต่อไปที่แผนที่ · การแตะนอกแผงฟังช่วง capture เพราะ Leaflet หยุดการส่งต่อเหตุการณ์บนแผนที่ ·
ขนาดแผนที่ยังอยู่ที่กล่องครอบ — `className` ของ `div` แผนที่ต้องคงที่ มิฉะนั้น React เขียนทับคลาสของ Leaflet แล้วภาพแผนที่ฐานหาย

## ความเป็นส่วนตัว (หน้าสาธารณะห้ามแสดงข้อมูลรายบ้าน)
- คำนวณฝั่ง server แล้วส่งออก **เฉพาะกรอบช่องและค่าเฉลี่ย** — ไม่มีพิกัดบ้านใน payload (เทสต์ whitelist ไว้)
- **ไม่แสดงช่องที่มีครัวเรือนน้อยกว่า 5 หลัง** (`GRID_MIN_HOUSEHOLDS`) — เกณฑ์เดียวกับตัวเลขสาธารณะอื่น
- นับเฉพาะแบบสอบถามที่ตรวจแล้ว ไม่นับใบซ้ำ/ใบที่ถูกลบ
- ค่าเฉลี่ยแต่ละตัวชี้วัดใช้ตัวหารเฉพาะหลังที่ตอบข้อนั้น และแสดงจำนวนหลังที่ตอบในกล่องข้อมูลของช่อง

## ข้อจำกัด
- เป็นค่าเฉลี่ยจากคำบอกเล่าของครัวเรือน ไม่ใช่แบบจำลองน้ำท่วมทางวิศวกรรม (บอกไว้ในกล่องข้อมูลทุกช่อง)
- ระดับน้ำเกิน 5 ม. เป็นข้อมูลจริง ไม่ถูกตัดทิ้ง (เจ้าของระบบยืนยัน)
- ช่องเป็นตารางตามพิกัด ไม่ใช่ตามเขตชุมชน — ช่องหนึ่งอาจคร่อมสองชุมชน
