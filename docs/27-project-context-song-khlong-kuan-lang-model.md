# docs/27 — บริบทโครงการแม่: สองคลองควนลังโมเดล

> บันทึกจากข้อมูลที่ Owner ให้ไว้เมื่อ 2026-07-22 — ใช้เป็นบริบทระดับโครงการสำหรับการออกแบบ
> ระบบ SKL-FRIS เป็น "ส่วนหนึ่ง" ของโครงการนี้ (แพลตฟอร์มฐานข้อมูล/ความเสี่ยง)

## 1. โครงการแม่

**สองคลองควนลังโมเดล** คือโครงการยกระดับคุณภาพชีวิตและลดความเหลื่อมล้ำ
ที่**มหาวิทยาลัยทักษิณ**นำโมเดลแก้จนจากพัทลุงมาขยายผลในพื้นที่**เทศบาลเมืองควนลัง จังหวัดสงขลา**
มุ่งเน้นการฟื้นฟู 5 ชุมชนเปราะบางระหว่าง **คลอง ร.1** และ **คลองอู่ตะเภา** (หมู่ที่ 1)

ผู้ถอดบทเรียน/ขับเคลื่อน: นพ.สุวัฒน์ วิริยพงษ์สุกิจ (มหาวิทยาลัยทักษิณ)

### หัวใจสำคัญของโมเดล

| แกน | สาระ | ส่วนที่ SKL-FRIS รองรับ |
|---|---|---|
| ฐานข้อมูลแม่นยำ | แพลตฟอร์มวิเคราะห์ทุนชีวิตและความเสี่ยงรายครัวเรือน | **โดยตรง** — household survey + risk calculation |
| ช่วยตรงจุด (ระยะสั้น) | เร่งดูแลกลุ่มเปราะบาง ผู้ป่วยติดเตียง บ้านที่ถูกน้ำท่วม | ข้อมูลกลุ่มเปราะบาง + assistance needs |
| ยั่งยืน (ระยะยาว) | เศรษฐกิจชุมชนพึ่งพาตนเอง (Pro-poor Value Chain, Social Safety Net) | นอกขอบเขตระบบปัจจุบัน (อาจใช้ข้อมูลอาชีพ/ทุนชีวิตในอนาคต) |
| รับมือภัยพิบัติ | เปลี่ยนชุมชนจาก "ผู้ประสบภัย" เป็น "ผู้ร่วมวางแผนและเตือนภัย" | เตือนภัย + จุดอพยพ + อาสาสมัคร + incident management |
| พลังร่วมมือ | มหาวิทยาลัย + ท้องถิ่น + เอกชน + ชุมชน | ระบบต้องรองรับผู้ใช้หลายสังกัด (registration/provisioning) |

## 2. ตัวเลขประชากรที่ได้รับแจ้ง (ยังไม่ใช่ค่ายืนยันสำหรับ seed)

| ชุมชน | สมาชิก (คน) — ตามข้อมูล Owner |
|---|---|
| ท่าเคียน | ~2,000 |
| หน้าควน | ~1,400 |
| ประสานมิตร | ~1,000 |
| ควนสันติ | ~1,200 |
| ปลักหว้า | ~900 |
| **รวม** | **~6,500 คน** |

ข้อความโครงการระบุอีกว่า "ประชากร 5 ชุมชนไม่ต่ำกว่า 5,000 **ครัวเรือน**" / "5 ชุมชน (กว่า 5,000 ครัวเรือน)"

### ⚠️ ข้อขัดแย้งของข้อมูลที่ต้องยืนยันก่อนใช้

ตัวเลข "สมาชิกรวม ~6,500 **คน**" กับ "ไม่ต่ำกว่า 5,000 **ครัวเรือน**" ขัดกันเชิงตรรกะ
(ครัวเรือนย่อมน้อยกว่าจำนวนคน — 6,500 คนโดยเฉลี่ยครัวเรือนละ ~3 คน ≈ ~2,200 ครัวเรือน)
สันนิษฐานได้ 2 ทาง:

1. "5,000 ครัวเรือน" อาจหมายถึง **5,000 คน** (หน่วยคลาดเคลื่อนในเอกสารประชาสัมพันธ์) หรือ
2. "สมาชิก" อาจนับเฉพาะสมาชิกที่ขึ้นทะเบียนกับชุมชน ไม่ใช่ประชากรทั้งหมด

**การตัดสินใจปัจจุบัน (สอดคล้อง CLAUDE.md):**
- `Community.totalHouseholds` ยังคง **NULL** จนกว่าจะได้ตัวเลขครัวเรือนที่ยืนยันจากพื้นที่จริง
- **ห้าม** seed ตัวเลขคน/ครัวเรือนข้างต้นเป็น `totalHouseholds` — คนละหน่วยกัน
- Coverage คำนวณได้เมื่อมี denominator จริงเท่านั้น (dashboard แสดง "ยังไม่ทราบจำนวนครัวเรือนรวม" ระหว่างนี้)

## 3. ผลต่อการออกแบบระบบ

1. **ชื่อ/แบรนด์สาธารณะ** — ระบบเป็นส่วนหนึ่งของ "สองคลองควนลังโมเดล" → หน้า public ควรอ้างอิงโครงการแม่ (เมื่อ Owner ยืนยันข้อความ)
2. **ผู้ใช้หลายสังกัด** — มหาวิทยาลัย/เทศบาล/เอกชน/ชุมชน → การลงทะเบียน (docs/26 §5) ต้องมีช่อง "สังกัด" และ approval ที่รู้ว่าใครมาจากไหน
3. **RESEARCHER role** — นักวิจัยมหาวิทยาลัยทักษิณคือผู้ใช้จริงของ role นี้ (ดูข้อมูล aggregate/anonymized เพื่อวิจัย)
4. **ขอบเขตภูมิศาสตร์** — พื้นที่จริงคือแนวคลอง ร.1 ↔ คลองอู่ตะเภา ในเขตเทศบาลเมืองควนลัง (ยังคงห้าม hardcode — เป็นข้อมูล ไม่ใช่ constraint ของโค้ด)
5. **เป้าหมายเชิงผลลัพธ์** — ระบบไม่ใช่แค่เก็บข้อมูล แต่ป้อน "ช่วยตรงจุด" (กลุ่มเปราะบาง/ติดเตียง/บ้านน้ำท่วม) → จัดลำดับความสำคัญของ module ความเปราะบางและ incident ให้สูง
